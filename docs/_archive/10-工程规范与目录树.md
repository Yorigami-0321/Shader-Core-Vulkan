## 二、命名规范

### 2.1 包名

```
dev.shadercore.vulkan.<layer>
```

| layer | 内容 |
|---|---|
| `device` | 设备、后端判定 |
| `engine` | 引擎生命周期 |
| `mesh` | 网格化 |
| `chunk` | 区块管理、剔除、批次 |
| `render` | 绘制 |
| `viewport` | 视口、视锥 |
| `translucent` | 半透明排序 |
| `shadow` | 阴影 |
| `config` | 配置 |
| `mixin` | mixin（只注入游戏） |
| `util` | 工具 |

### 2.2 类名

| 类型 | 规范 | 样例 |
|---|---|---|
| 普通类 | PascalCase | `VulkanChunkEngine` |
| 枚举 | PascalCase，成员 UPPER_SNAKE | `BackendKind.VULKAN` |
| 记录（数据载体） | PascalCase | `ChunkSnapshot` |
| 接口 | PascalCase | `ShadercoreVertex` |
| 常量 | UPPER_SNAKE | `REGION_SIZE` |
| 工具类 | 复数或 -s | `Checks` |
| Mixin | 目标名 + `Mixin` | `GameRendererMixin` |

### 2.3 方法名

| 类型 | 规范 | 样例 |
|---|---|---|
| 普通方法 | camelCase，动词开头 | `renderChunks` |
| 布尔返回 | `is` / `has` / `can` 开头 | `isAvailable` |
| 工厂 | `of` / `create` / `from` | `of(camera)` |
| 访问器 | getter `x()`，setter `x(v)` | `frame()` / `frame(n)` |

### 2.4 字段名

| 类型 | 规范 |
|---|---|
| 实例字段 | camelCase |
| 常量 | `static final` UPPER_SNAKE |
| 私有字段 | camelCase，不加 `m` 前缀 |
| 日志 | `private static final Logger LOGGER` |

## 三、build.gradle（完整）

```groovy
plugins {
    id 'java'
    id 'net.neoforged.moddev' version "${moddevgradle_version}"
}

version = "${mod_version}+mc${minecraft_version}"
group = 'dev.shadercore'

java {
    toolchain {
        languageVersion = JavaLanguageVersion.of(java_version as int)
    }
}

neoForge {
    version = neoforge_version
    // 如需 run client：
    // runs { client { client() } }
}

repositories {
    mavenCentral()
    maven { name = 'NeoForged'; url = 'https://maven.neoforged.net/releases' }
    // 路线 C：官方 API 制品
    maven { name = 'CaffeineMC'; url = 'https://maven.caffeinemc.net/releases' }
    maven { name = 'Fabric'; url = 'https://maven.fabricmc.net/' }
}

dependencies {
    // 路线 C：只依赖官方公开 API（PolyForm 明确欢迎）
    compileOnly "net.caffeinemc:sodium-neoforge-api:${sodium_api_version}"

    compileOnly "net.fabricmc:sponge-mixin:${mixin_version}"
    compileOnly "io.github.llamalad7:mixinextras-common:${mixinextras_version}"
}

tasks.named('jar', Jar) {
    manifest {
        attributes(
            'Implementation-Title': 'Shader Core Vulkan',
            'Implementation-Version': project.version
        )
    }
}

// 构建后自动校验
tasks.named('build') {
    finalizedBy 'verifyJar'
}

tasks.register('verifyJar', Exec) {
    dependsOn 'jar'
    commandLine 'bash', 'scripts/verify-jar.sh'
}
```

## 五、mods.toml（完整）

```toml
modLoader="javafml"
loaderVersion="[4,)"

[[mods]]
modId="shadercore-vulkan"
version="${mod_version}"
displayName="Shader Core Vulkan"
license="MIT"
authors="shadercore"
description="Vulkan chunk rendering backend for Vitrail-Shaders on Minecraft ${minecraft_version} NeoForge. Uses official Minecraft render APIs."
logoFile="assets/shadercore/icon.png"
displayTest="IGNORE_ALL_VERSION"

[[dependencies.shadercore-vulkan]]
modId="minecraft"
type="required"
versionRange="[${minecraft_version},${minecraft_next})"
ordering="NONE"
side="CLIENT"

[[dependencies.shadercore-vulkan]]
modId="neoforge"
type="required"
versionRange="[${neoforge_min_version},)"
ordering="NONE"
side="CLIENT"
```

> ⚠️ `[[dependencies.<X>]]` 的 `<X>` **必须等于** `modId`。

## 六、shadercore-vulkan.mixins.json

```json
{
  "required": true,
  "minVersion": "0.8.5",
  "package": "dev.shadercore.vulkan.mixin",
  "compatibilityLevel": "JAVA_25",
  "injectors": {
    "defaultRequire": 1
  },
  "client": [
    "GameRendererMixin",
    "LevelRendererMixin"
  ],
  "mixins": []
}
```

> **`compatibilityLevel` 必须是 `JAVA_25`。** 写 `JAVA_21` 在 Java 25 下 mixin 会被静默跳过。
