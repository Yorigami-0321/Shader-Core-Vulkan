## 0. 🔴 三支柱（项目目标，2026-10-02 用户指令，最高优先级）

> 「目的依旧是**高性能，稳定，以及保持兼容性让 optfine/iris 着色器完整的运行在 vulkan 上**。」

| 序 | 支柱 | 唯一度量 | 冲突时 |
|---|---|---|---|
| ① | **兼容** | pack × program 兼容矩阵（`08` §10） | **优先级最高** |
| ② | **稳定** | 崩溃 / validation error = 0；无静默降级 | 次之 |
| ③ | **高性能** | B1 帧时间 ≤ +2%；B3 冷路径 ≤ 1s；B4 切包 ≤ 2s | 最后 |

**三支柱直接改写了三条旧铁律**（2026-10-02）：

| 旧铁律 | 新口径 | 依据 |
|---|---|---|
| 默认零 mixin，全局只许 1 个注入点 | **mixin 松绑到「管线装配层」**，登记制 + 可关闭制 + 逐个开启 | 零 mixin 路线**已被源码级证伪**（GAP-003/004 三条路全断），而兼容是最高支柱 |
| 冷路径（解析/预处理/转译）一律纯 Java | **允许实测**，走 G 系列闸门，≥20% 净收益才采用 | 「冷路径无收益」推理过度：冷路径决定**切包等待**（B3/B4），不是帧率 |
| C++/Rust 是未验证的可选项 | **列为 G 线实测对象**（范围：`glsl/` 转译 + `pack/` 解析） | 用户明确要求测试 Rust vs Java 差异 |

⚠️ **新增禁止**：不许为性能砍掉 pack 特性（`07` X27）。
