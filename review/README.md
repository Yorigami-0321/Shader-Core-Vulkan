## 三、为什么保留这些过时文档（而不是全删）

它们承载了两样删不掉的东西：

1. **X 系列红线的历史依据** —— `07-CONSTRAINTS.md` 的 X1–X56 全部来自 `2026-09-30-代码质量审查与改进方案.md`。
   删掉它就等于删掉了条款的出处，将来无法回答「这条为什么存在」。
2. **审查方法学** —— 「统计方法长度必须排除 `record`/`class`/`interface` 声明行」
   「报数前先人工验证 1 个样本」等，已升格为 `07` §九自检清单条款。

⇒ 所以做法是**加状态头 + 指向真源**，而不是删除。
